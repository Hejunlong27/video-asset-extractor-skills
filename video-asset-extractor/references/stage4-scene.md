# 阶段4：场景生图提示词生成

## 输入变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `stage1_output` | String（MD文本） | 阶段1输出的资产清单 |
| `script` | String | 原始剧本文本（用于回溯验证） |

## 输出格式

Markdown 格式场景提示词。

---

## 处理步骤

### Step A：共用光色锚点提取

**动作：**
对每个核心场景，从剧本中提取该场景的光照与色彩信息。

**提取内容：**
1. 时间段（日/夜/晨/黄昏/具体时间）
2. 天气（晴/阴/雨/雪/雾）
3. 主光源方位及色温（K值）（如 右侧暖黄日光4500K / 顶部冷白月光6500K）
4. 补光源及色调（如 竹叶冷绿补光 / 烛火暖橙补光）
5. 整体色调（如 青绿暖黄交替 / 冷蓝灰）
6. 对比度（高/中/低）
7. 空气中颗粒/雾气/尘埃描述（如 细密竹叶碎光 / 薄雾弥漫 / 尘埃浮动）

**规则：** 光色锚点为该场景所有视角（俯视图 + 九宫格9格）强制共用的基础描述，禁止在不同视角间修改。

---

### Step B：俯视全景图提示词生成

**动作：**
从剧本中提取场景的空间布局信息，生成俯视正交投影顶视图提示词。

**提取内容：**
1. 空间尺寸（如 8m x 6m 矩形空间）
2. 地面材质颜色（如 青石板地面/夯土地面）
3. 固定陈设落位（逐一列出：陈设名称 + 位置坐标 + 尺寸）
4. 出入口方位及宽度（如 北侧门宽1.2m / 东侧窗宽2m）

**模板：**
```text
90度俯视正交投影顶视图，纯白背景，{场景名}精准平面布局图。{空间尺寸}，{地面材质颜色}，{逐一列出固定陈设落位：陈设A位置+尺寸，陈设B位置+尺寸，陈设C位置+尺寸，出入口方位+宽度}。带浅灰色尺寸标注线和比例尺，建筑轴测图风格，清晰线条，无透视变形，工业化制图，哑光质感，无人物，超清 --ar 1:1
```

---

### Step C：九宫格分镜图提示词生成

**动作：**
基于光色锚点 + 俯视图布局，生成9格多视角一致性矩阵提示词。

**模板：**
```text
九宫格矩阵拼图，纯白背景，3x3排列。严格共用光色锚点（{时间/光源/色调}）。9格内容如下：
格1远景广角平视（相机高度1.6m）展现{场景名}全局空间纵深感，所有陈列入镜；
格2中景正拍平视正对{核心视觉中心}；
格3近景俯拍微距聚焦{地面/桌面肌理}；
格4贴地仰拍强调{高处物体}高大感；
格5 45度俯拍清晰显示{陈设A}、{陈设B}、{出口}相对落位；
格6左侧边缘平视带入{左侧特有元素}；
格7右侧平行平视阳光直射{右侧墙面/地面}；
格8东北角向西南对角线斜切透视感最强；
格9特定细节微距聚焦{某处磨损/纹理}。
确保地面砖缝尺寸、陈设位置在9格内完全匹配。顶部空白处黑体加粗中文标注"{场景名}—多视角一致性矩阵"。电影场景设定集，写实渲染，8k，无人物，固定焦距 --ar 1:1
```

---

### Step D：简化单视角提示词生成

**模板：**
```text
{场景名}，[🔒共用光色锚点]，{空间布局简述}，{核心陈设}，广角平视，电影场景，写实渲染，8k，无人物 --ar 16:9
```

---

### 一致性自检 ⑧：光色锚点一致性 + 陈设位置匹配

**校验项 1 — 光色锚点跨视角一致性：**
- 对每个场景，将光色锚点与俯视图提示词、九宫格提示词中的光色描述逐项对比
- 要求：时间段、天气、主光源方位及色温、补光源、整体色调、对比度完全一致
- 异常处理：发现差异 → 以光色锚点为准，强制覆盖其他视角中的光色描述

**校验项 2 — 陈设位置跨视角匹配：**
- 对比俯视图中的陈设落位与九宫格各格中提到的陈设
- 要求：九宫格格5（45度俯拍）中显示的陈设相对位置必须与俯视图一致
- 要求：九宫格各格中提到的陈设必须在俯视图中有对应落位
- 异常处理：位置不一致 → 以俯视图为准，修正九宫格描述

**校验项 3 — 出入口方位一致：**
- 检查九宫格中提到的出入口方向是否与俯视图一致
- 异常处理：不一致 → 以俯视图为准修正

**校验项 4 — 场景内无穿帮物品：**
- 检查场景陈设中是否有与剧本时代不符的物品
- 对照规则：古装场景不应有电灯/塑料/现代家具；近代场景不应有智能手机等
- 异常处理：发现穿帮 → 移除该物品并记录

**校验项 5 — 场景间区分度：**
- 检查同类场景（如多个室内场景）是否有足够区分度
- 异常处理：区分度不足 → 增加独有陈设或光色特征

**输出：** `✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`
