# 阶段3：道具生图提示词生成

## 输入变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `stage1_output` | String（MD文本） | 阶段1输出的资产清单 |
| `script` | String | 原始剧本文本（用于回溯验证） |

## 输出格式

Markdown 格式道具提示词。

---

## 处理步骤

### Step A：物理尺寸比例卡生成

**动作：**
对每个核心道具，从剧本中提取尺寸线索（如"三尺长剑""掌心大小"），结合道具类型常识推断具体数值。

**提取内容：**
1. 全长/直径（cm）
2. 宽/径（cm）
3. 厚度/高度（cm）
4. 重量（g/kg）
5. 与角色身体的比例（约为角色身高的X分之一 / 约为手掌的X倍）
6. 持握方式（单手/双手）
7. 重心位置

**规则：** 剧本有明确尺寸描述时优先使用剧本数据；无明确描述时根据道具类型 + 时代背景推断，并标注「推断」。

---

### Step B：材质色彩构成卡生成

**动作：**
从剧本中提取材质描述词（如"玄铁""乌木""白玉"），分解为主材 + 辅材 + 表面处理。

**提取内容：**
1. 主材质A：名称 + 颜色 + 占比（%）
2. 辅材质B：名称 + 颜色 + 占比（%）
3. 辅材质C：名称 + 颜色 + 占比（%）（如有）
4. 反光特性：高/中/低 + 金属/哑光/透光
5. 表面处理：抛光/磨砂/做旧/包浆/生锈

---

### Step C：结构细节特写卡生成

**动作：**
从剧本中提取结构描述（如"双开刃""剑身刻有铭文"），分解为部件级描述。

**提取内容：**
1. 整体轮廓（一句话概括形态）
2. 部件A（主体）：形状 + 边缘处理
3. 部件B（连接处/柄头）：纹路/铭文/缠绳方式
4. 部件C（附属部件，如有）：描述
5. 独有磨损：具体划痕位置/锈迹分布/破损形态（如剧本未提及，标注"无明显磨损标记"）

---

### Step D：标准化设定卡生图提示词生成

**动作：**
基于上述三卡信息，生成四分格设定卡生图提示词。

**模板：**
```text
四分格构图设定卡，纯白背景。区域1（左上）：{道具名}全貌写实摄影，整体展示；区域2（右上）：物理尺寸比例示意图，带标尺与人体手掌对比；区域3（左下）：材质与色彩样本拆解，展示{具体纹理/色块}；区域4（右下）：微距特写，聚焦{铭文/纹路/磨损}。四幅图间隔分明。画面上下空白处用清晰黑体加粗中文大字标注"{道具名}"。工业设计蓝图风格，商业产品摄影级，8k，超高清，固定视角，无阴影干扰 --ar 1:1
```

---

### Step E：简化单视角提示词生成

**模板：**
```text
{道具名}，{整体轮廓}，{主材质及颜色}，{独有特征}，纯白背景，产品摄影，微距细节，8k --ar 1:1
```

---

### 一致性自检 ⑦：尺寸比例合理性 + 材质物理可行性

**校验项 1 — 尺寸与角色体型匹配：**
- 检查道具尺寸与持有角色体型的比例是否合理
- 对照规则：
  - 儿童角色持长兵器：需标注比例调整（如"此道具为儿童版，全长缩短至成人版的2/3"）
  - 女性角色持重型兵器：重量需合理（单手不超过3kg）
  - 道具长度不超过场景空间尺寸的合理比例
- 异常处理：比例不合理 → 调整尺寸数值或增加比例调整注释

**校验项 2 — 材质物理可行性：**
- 检查材质组合是否物理可行
- 对照规则：
  - 金属剑身不应描述为"透光"（除非是特殊材质设定）
  - 木质部件不应描述为"高金属反光"
  - 占比总和应为100%（±5%误差允许）
  - 重量与材质密度匹配（如纯铁剑全长100cm不可能仅重200g）
- 异常处理：物理不可行 → 修正材质描述或重量数值

**校验项 3 — 结构与剧本一致：**
- 回溯剧本原文，验证结构描述（双开刃/单开刃/有无铭文等）与剧本一致
- 异常处理：与剧本矛盾 → 以剧本为准修正

**校验项 4 — 道具间区分度：**
- 检查同类道具（如多把剑）是否有足够区分度
- 异常处理：区分度不足 → 增加独有磨损/铭文/颜色差异

**输出：** `✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`
