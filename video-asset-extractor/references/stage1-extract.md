# 阶段1：剧本解析与资产提取

## 输入变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `script` | String | 完整剧本文本 |
| `frequency_threshold` | Integer | 频次阈值，默认 `5` |

## 输出格式

Markdown 格式资产清单（见下方输出模板）。

---

## 处理步骤

### Step 0：剧本预处理

**动作：**
1. 清除多余空白与重复换行
2. 统一全/半角标点（逗号、句号、引号、冒号等）
3. 识别场景标题模式（"第X场"/"场景："/"INT./EXT."/"【场景】"等），按标题切分为场景单元
4. 容错兜底：无明确标题时，按空行 + 角色名行（行首为角色名+冒号/空格）启发式切分

**一致性自检 ①：预处理完整性**
- 校验项：原文字数丢失率 < 2%（对比清洗前后字符数）
- 校验项：场景单元数 ≥ 3（若 < 3 标记为短剧本，触发自适应阈值）
- 校验项：标点已统一（无混用全/半角）
- 异常处理：丢失率 > 2% → 回退，仅去空白不去标点；场景 < 3 → 标记并继续
- 输出：`✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`

---

### Step 1：结构化解析

**动作：**
对每个场景单元提取以下字段：
- 场景标题（原始标题文本）
- 内外景（内景/外景/室内外）
- 时间段（日/夜/晨/黄昏/具体时间）
- 角色出场列表（该场景中出现的所有角色名）
- 对话内容（各角色的台词）
- 动作/环境描述（舞台指示、动作描写、环境描写）

**一致性自检 ②：解析字段完整性**
- 校验项：每个场景单元至少包含「角色出场列表」和「动作/环境描述」两个字段
- 校验项：无孤立对话（每段台词都有对应角色归属）
- 校验项：角色名无拼写不一致（如"李慕白"与"李慕白 "视为同一人，合并别名）
- 异常处理：缺失字段 → 从上下文推断补全；孤立对话 → 归入最近出场的角色
- 输出：`✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`

---

### Step 2：频次统计

**动作：**
1. 角色频次：同一场景单元内多次提及同一角色只算 1 次，跨场景单元累计
2. 道具频次：同一场景单元内多次提及同一道具只算 1 次，跨场景单元累计
3. 场景频次：同一场景名出现多次时累计（注意区分"竹林精舍-日"和"竹林精舍-夜"为同一场景的不同时段）

**一致性自检 ③：频次计数正确性**
- 校验项：抽查 3 个高频资产，手动回溯剧本验证其在各场景单元的出现记录与计数一致
- 校验项：同一场景内重复提及确未重复计数
- 校验项：同名场景的不同时段未被误合并或误拆分
- 异常处理：计数错误 → 重新统计该资产；合并/拆分错误 → 修正后重新计数
- 输出：`✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`

---

### Step 3：阈值过滤

**动作：**
1. 自适应阈值：若场景单元总数 < 10，自动将阈值降为 `max(2, ⌊场景数/3⌋)`，记录调整原因
2. 频次 ≥ 阈值 → 核心资产（入库，进入后续提示词生成）
3. 频次 < 阈值 → 低频资产（仅记录名称，不生成提示词）
4. 输出核心资产列表与低频资产列表

**一致性自检 ④：阈值过滤合理性**
- 校验项：自适应阈值计算正确（场景数 < 10 时确认已触发）
- 校验项：核心资产总数 ≥ 3（角色+道具+场景合计）；若 < 3 → 降低阈值重新过滤
- 校验项：无重要资产被误过滤（检查低频资产中是否有对剧情关键的角色/道具/场景）
- 异常处理：核心资产 < 3 → 阈值降1重新过滤，最多降2次；关键资产被误过滤 → 手动提升为核心资产
- 输出：`✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`

---

### Step 4：变体检测

**动作：**
1. 对每个核心角色/道具，检索其所在**场景单元全文**及**前后各 1 个相邻场景单元**
2. 检索关键词类型：
   - 服饰词：道袍/夜行衣/甲胄/布衣/正式礼服/素服等
   - 时间词：三年前/关键剧情期/雨夜/少年时/老年等
   - 状态词：受伤/改扮/变装/醉酒/衰老等
3. 若检索到 ≥ 2 种不同描述 → 标记为多版本变体，记录每个变体的触发词来源场景
4. 若仅 1 种描述 → 标记为单一版本，无变体分支

**一致性自检 ⑤：变体检测覆盖度**
- 校验项：变体检测窗口确已覆盖「所在场景 + 前后各1个相邻场景」
- 校验项：每个标记为多版本的资产，其变体描述均有剧本原文依据（回溯引用原文片段）
- 校验项：无遗漏变体（对高频角色额外检查全文是否有未被窗口覆盖的服饰/时间变化）
- 异常处理：遗漏变体 → 补充检测；无原文依据的变体 → 删除
- 输出：`✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`

## System Prompt

```markdown
你是剧本视觉资产提取师，负责阶段1：剧本解析与资产提取。

**处理规则：**
1. 按Step 0-4顺序执行，每个Step完成后立即执行对应的一致性自检。
2. 预处理时注意容错：无标准场景标题时按空行+角色名行启发式切分。
3. 频次统计：同一场景单元内重复提及只算1次，跨场景累计。
4. 自适应阈值：场景单元 < 10时，阈值降为 max(2, ⌊场景数/3⌋)。
5. 变体检测窗口：所在场景 + 前后各1个相邻场景。
6. 一致性自检未通过时自动修正，并在「修正记录」中记录。
7. 输出为Markdown格式，严格按输出模板生成。

**输入：**
- 剧本内容：{{script}}
- 频次阈值：{{frequency_threshold}}（默认5）
```
