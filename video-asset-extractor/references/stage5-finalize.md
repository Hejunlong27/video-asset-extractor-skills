# 阶段5：负向提示词生成与最终装配

## 输入变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `stage2_output` | String（MD文本） | 阶段2输出的角色提示词 |
| `stage3_output` | String（MD文本） | 阶段3输出的道具提示词 |
| `stage4_output` | String（MD文本） | 阶段4输出的场景提示词 |
| `output_format` | String | 输出格式："md"（默认）或 "json" |
| `platform` | String | 目标平台："midjourney"（默认）/ "sd" / "domestic" |

## 输出格式

默认 Markdown；仅当 `output_format` 为 "json" 时输出 JSON。

---

## 处理步骤

### Step A：负向提示词生成

**动作：**
为每类资产生成配套的负向提示词（negative prompt）。

**角色负向提示词基线：**
```
换脸, 面部变形, 双瞳颜色不一致, 左右不对称, 多余手指, 年龄偏差, 发色突变, 服装穿越, 现代配饰, 水印, 文字, 模糊, 低质量
```
- 对每个变体追加该变体特有的排除项（如夜行衣变体追加"夜行衣不应有反光金属"）

**道具负向提示词基线：**
```
比例失真, 尺寸不一致, 材质混乱, 多余部件, 反光过曝, 文字水印, 卡通化, 低多边形, 模糊, 手持时变形
```
- 对特殊材质道具追加排除项（如透光材质追加"不透明"）

**场景负向提示词基线：**
```
光色不一致, 陈设位置偏移, 穿帮物品, 时代不符的物件, 人物出现, 透视变形, 色温突变, 水印, 文字, 模糊
```
- 对夜景场景追加"日间光线"；对室内场景追加"室外景物穿入"

---

### Step B：多平台语法适配

**动作：**
根据 `platform` 参数，对所有提示词进行语法适配。

| 平台 | 适配操作 |
|------|---------|
| **midjourney**（默认） | 保持 `--ar` 参数，关键锚点用 `::` 加权（如 `面部锁定锚点::2`） |
| **sd** (Stable Diffusion) | 移除 `--ar` 参数（在生成参数中设置尺寸），面部/尺寸/光色锚点用 `(())` 或 `(关键词:1.3)` 加权包裹，负向提示词填入 negative prompt 框 |
| **domestic**（通义万相/即梦） | 移除所有平台参数，使用「简化单视角提示词」分批生成，负向提示词作为自然语言排除描述附加在提示词末尾 |

**输出规则：** 在最终资产包中，每个资产的提示词按目标平台语法输出。若用户未指定平台，默认 midjourney。

---

### Step C：跨资产最终一致性自检

**一致性自检 ⑨：跨资产最终校验**

这是全工作流的**最终关卡**，综合校验三类资产之间的交叉一致性。

**校验项 1 — 角色服装与场景时代匹配：**
- 逐一检查每个角色的标准服装及变体服装，是否与其出场的核心场景的时代设定一致
- 对照：古装角色不应在现代场景中穿现代服装（除非剧情要求穿越）
- 异常处理：不匹配 → 修正服装或场景描述，记录修正

**校验项 2 — 道具尺寸与角色体型匹配：**
- 逐一检查每个核心道具的物理尺寸，是否与持有该道具的角色体型比例合理
- 对照：儿童角色持长剑需标注比例调整；女性角色持重型兵器需检查重量合理性
- 异常处理：不合理 → 调整道具尺寸或增加比例注释，记录修正

**校验项 3 — 道具材质与场景光色匹配：**
- 检查道具材质的反光特性是否与场景光色锚点兼容
- 对照：高金属反光道具在暗光场景中需有补光描述；透光材质道具在强光场景中需有过曝控制
- 异常处理：不兼容 → 在道具提示词中增加光照适配描述

**校验项 4 — 场景陈设与道具一致性：**
- 检查在场景俯视图中出现的道具，是否与核心道具列表一致
- 对照：场景中固定摆放的道具（如墙上挂剑）应在道具资产中有对应条目
- 异常处理：不一致 → 补充遗漏道具或修正场景陈设描述

**校验项 5 — 负向提示词完整性：**
- 检查每个资产（含变体）是否都有对应的负向提示词
- 异常处理：缺失 → 按基线模板补全

**校验项 6 — 平台适配正确性：**
- 检查所有提示词的语法是否与目标平台一致
- 对照：sd平台不应残留 `--ar` 参数；domestic平台应使用简化单视角提示词
- 异常处理：不一致 → 按目标平台重新适配

**输出：** `✅通过` / `⚠️警告（附详情）` / `❌失败（附原因）`

## System Prompt

```markdown
你是影视视觉资产提取师，负责阶段5：负向提示词生成与最终装配。

**处理规则：**
1. 汇总阶段2（角色）、阶段3（道具）、阶段4（场景）的输出。
2. 为每个资产（含变体）生成配套负向提示词，在基线基础上追加资产特有排除项。
3. 根据platform参数对所有提示词进行语法适配（midjourney/sd/domestic）。
4. 执行一致性自检⑨（跨资产最终校验：6个校验项）。
5. 自检未通过时自动修正并记录。
6. 默认输出Markdown格式；仅当output_format为"json"时输出JSON。
7. 汇总全工作流（阶段1-5）所有修正记录。

**输入：**
- 阶段2输出：{{stage2_output}}
- 阶段3输出：{{stage3_output}}
- 阶段4输出：{{stage4_output}}
- 输出格式：{{output_format}}（默认md）
- 目标平台：{{platform}}（默认midjourney）
```
