# 剧本视觉资产提取器 — 多阶段工作流编排器

## 概述

本 Skill 是**编排器**，协调以下 5 个阶段按顺序执行。每个阶段独立输出，阶段间通过 Markdown 文本传递数据。每一步处理完成后均执行**一致性自检验证**，确保资产提取与剧本保持一致。

每个阶段的详细处理步骤、模板和 System Prompt 存放在 `references/` 目录下，执行对应阶段前**必须先读取**对应参考文件。

## 工作流总览

```
剧本文本
    │
    ▼
┌─────────────────────────────────┐
│  阶段1: 剧本解析与资产提取       │  剧本预处理 → 结构化解析 → 频次统计 → 阈值过滤 → 变体检测
│  (每步附带一致性自检 ① ~ ⑤)      │
│  输出: 资产清单 (MD)             │
└──────────┬──────────────────────┘
           │ 资产清单 + 原始剧本
     ┌─────┼─────┐
     ▼     ▼     ▼
  ┌──────┐┌──────┐┌──────┐
  │阶段2  ││阶段3  ││阶段4  │  角色/道具/场景提示词生成（可并行）
  │角色   ││道具   ││场景   │
  │+自检⑥ ││+自检⑦ ││+自检⑧ │
  └──┬───┘└──┬───┘└──┬───┘
     │        │        │
     └────┬───┴────────┘
          ▼
  ┌───────────────────┐
  │  阶段5: 负向提示词与最终装配  │  负向提示词 → 多平台适配 → 跨资产最终一致性自检⑨
  │  输出: 完整资产包 (MD/JSON)    │
  └───────────────────┘
```

## 各阶段与参考文件

| 阶段 | 参考文件 | 输入 | 输出 | 一致性自检 |
|------|---------|------|------|-----------|
| **阶段1** | `references/stage1-extract.md` | 剧本文本 + 频次阈值 | 资产清单（MD） | ①预处理完整性 ②解析字段完整性 ③频次计数正确性 ④阈值过滤合理性 ⑤变体检测覆盖度 |
| **阶段2** | `references/stage2-character.md` | 阶段1输出 + 原始剧本 | 角色提示词（MD） | ⑥面部锚点一致性 + 服装时代匹配 |
| **阶段3** | `references/stage3-prop.md` | 阶段1输出 + 原始剧本 | 道具提示词（MD） | ⑦尺寸比例合理性 + 材质物理可行性 |
| **阶段4** | `references/stage4-scene.md` | 阶段1输出 + 原始剧本 | 场景提示词（MD） | ⑧光色锚点一致性 + 陈设位置匹配 |
| **阶段5** | `references/stage5-finalize.md` | 阶段2-4输出 | 完整资产包（MD或JSON） | ⑨跨资产最终校验 + 负向提示词完整性 |

## 执行规则

1. **顺序执行**：阶段1必须先完成，阶段2/3/4可并行，阶段5必须最后执行。
2. **读取参考文件**：执行每个阶段前，必须先读取 `references/` 目录下对应的 `.md` 文件，严格按照其中的处理步骤、输出模板和 System Prompt 执行。
3. **数据传递**：每个阶段的输出（MD格式）作为下一阶段的输入。阶段1输出需同时传递给阶段2/3/4。
4. **一致性自检**：每个步骤完成后立即执行对应的一致性自检，自检未通过时自动修正并在输出中记录修正内容。
5. **输出格式**：默认输出 Markdown 格式。仅当用户明确要求 JSON 格式时，阶段5才输出 JSON。
6. **原始剧本保留**：所有阶段均可访问原始剧本文本，用于回溯验证。

## 调用方式

向用户确认以下参数后开始执行：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `script` | String | 必填 | 完整剧本文本 |
| `frequency_threshold` | Integer | 5 | 频次阈值（阶段1自适应调整） |
| `output_format` | String | "md" | 输出格式："md" 或 "json" |
| `platform` | String | "midjourney" | 目标平台："midjourney" / "sd" / "domestic" |

执行流程：
1. 读取 `references/stage1-extract.md`，按其指引执行阶段1，传入剧本和阈值，获得资产清单
2. 读取 `references/stage2-character.md`、`references/stage3-prop.md`、`references/stage4-scene.md`，将资产清单 + 原始剧本分别传入执行（可并行）
3. 读取 `references/stage5-finalize.md`，汇总阶段2-4输出，获得最终资产包
